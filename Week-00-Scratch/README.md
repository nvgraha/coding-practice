# 📦 CS50x – Week 0: Scratch Project  
## 🎮 Project: Tsunami Surf
Welcome to my very first CS50x project — a game created using [Scratch](https://scratch.mit.edu/).\
In this simple interactive game, the player controls a surfboard sprite that must avoid getting attacked by a shark, to gain a point player needs to collect the gold to increase their score. The game showcases key programming concepts such as conditionals, loops, variables, and custom blocks.
***
## 🔗 Live Project Link
👉 [Click here to play "Tsunami Surf"](https://scratch.mit.edu/projects/943169345)
***
## 🧩 How the Game Works
- The **pirate sprite** follows the mouse horizontally.
- The **shark sprite** emerges from the bottom of the screen.
- The score increases if the player able to **collect the gold**.
- If the **shark attacks the pirate**, the score decreases and the shark resets to the bottom.
- The **game** uses loops, broadcasts, and conditionals to keep running continuously.
***
## 💡 What I Learned
- How to translate logic into visual blocks using Scratch
- Core programming ideas: conditionals, loops, variables, and events
- How to build modular code using **custom blocks**
- Interactive game design and player feedback
- Debugging using visual tools and testing behavior step-by-step
***
## 🛠️ How to Run the Project
1. Visit the [project link](https://scratch.mit.edu/projects/943169345)
2. Click the green flag to start the game
3. Move your arrow keys to control the surfboard and catch the flying golds
4. Watch your score increase as you play!
